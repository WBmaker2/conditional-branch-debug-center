`tests/release/pages-assets.test.ts`가 `src/assets` 파일과 이 장부의 대응을 검사한다.

| 파일 | 제작 방법 | 프롬프트 / 제작 메모 | 생성일 | 사용 위치 | 권리 |
|---|---|---|---|---|---|
| `src/assets/generated/branch-control-room.svg` | 사람이 직접 작성한 SVG 코드(이미지 생성 모델 미사용) | 밝은 교실형 제어실 입구 그림: 작업대 위 가상 전등·화분·선풍기·버스 정류장 표지와 규칙 레일, 분기 다이아몬드. 글자·정답 문자 없음. 색만으로 정보를 전달하지 않음 | 2026-08-28 | 입구 화면 히어로 이미지 (`EntranceScreen.tsx`) | 프로젝트 자체 제작. 외부 소스·라이선스 의존 없음 |

## 대체 경위

계획 §10은 이미지 생성 모델 자산을 전제하지만, 이 환경에서는 생성 모델을 쓸 수 없어
계획이 허용한 대체 경로("실패 시 CSS 도형만으로 대체")에 따라 코드로 직접 SVG를 작성했다.
따라서 생성 모델 편향·권리 리스크가 없으며, 규칙 레일·참/거짓 표식·갭·겹침 도식은 계획대로
React/CSS·SVG로 렌더링한다. 이미지를 불러오지 못해도 제목·지시·선택지·판정·보고서로 학습을 완주할 수 있다.

## 사람 검수 대기 항목

- [ ] SVG 그림이 학교 현장 맥락에 맞는지(성별·직업 고정관념 없음, 대비 충분)
- [ ] 이후 이미지 생성 모델 자산을 추가하면 프롬프트·생성일과 함께 이 표에 추가한다
