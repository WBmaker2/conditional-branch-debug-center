# 콘텐츠 검수 기록 (content-review)

계획 문서 §4·§4.1의 고정 fixture를 기준으로 2026-08-28에 작성했다.
`src/content/missions.ts`의 `reviewStatus: "approved"`는 **계획에 적힌 고정 fixture·판정 규칙과의 일치를 자동 검수(validateContent)가 통과했음**을 뜻한다.
그것은 사람 검수를 대신하지 않는다. 아래 사람 검수 항목이 채워지기 전까지 실제 수업 사용과 공개 출시를 하지 않는다.

## 사람 검수 대기 항목 (출시 전 필수)

- [ ] 교과 정확성: 비교 연산자(초과·이상·미만·이하)와 갭·겹침 용어의 교과 표현 일치
- [ ] 어린이 문장 난이도: 화면 문장이 초등 5~6학년 수준인지
- [ ] 오개념 방지 문구(misconceptionGuard)의 지도 적절성
- [ ] 생성/제작 시각 자산의 맥락·편향·권리 확인 (`docs/image-rights-ledger.md`)
- [ ] 실제 태블릿(320px~768px) 가독성

## 교육 모형의 한계 고지

이 앱의 전등·화분·선풍기·분류기·버스는 학습용 가상 모형이다. 실제 기기·교통·안전 시스템을
제어하거나 그 결과를 보장하지 않는다. 각 미션 화면의 피드백에도 같은 문장을 표시한다.

## 개인정보·안전

- 학생 이름, 학급 사건, 위치, 사진, 생년월일 입력란 없음.
- 응답은 탭 메모리에만 존재하고 서버 전송·저장소 기록이 없음을 `tests/privacy/runtime-boundary.test.ts`가 자동 검사한다.
- 인쇄 결과에 이름 입력란·식별자·브라우저 메타데이터를 넣지 않는다.
